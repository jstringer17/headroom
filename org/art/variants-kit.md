# Higgsfield picture kit: variants
Made from sitemaker/src/cine-kit.js (prompts from org/art/variants-prompts.json). Run `node org/art/kit-doc.mjs` after any change.

**Total: 90 new pictures** for 3 trades (about 180 credits at 2 per 2K picture). The first look of each trade is the main kit (higgsfield-kit.md) and is not repeated here.

| Trade | Variants | New pictures |
|---|---|---|
| Roofing | Asphalt shingle (main kit), Standing-seam metal, Clay or concrete tile, Slate, Cedar shake, Flat or low-slope | 30 |
| Fencing | Cedar privacy (main kit), White vinyl privacy, Black aluminum picket, Chain link, Split-rail ranch, Modern horizontal slat | 30 |
| Pressure Washing | Driveway and walkway (main kit), House siding, Deck and patio, Fence, Roof soft wash, Storefront and lot | 30 |

## How to make them
1. Same rules as the main kit: wide 16:9, no people, no faces, no text, no logos.
2. Each variant is one scene: make s1 new, then use **Edit** on the newest picture for s2, s3 and s4.
3. Make "before" new, then use **Edit** on it for "after".
4. Save each file as `<trade>-<variant>-<slot>.jpg` (like `roofing-metal-s1.jpg`). Its place in the library is library/<trade>/<variant>/<slot>.webp (cine-engine is adding variant folders to the ingest script).
