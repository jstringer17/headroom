# Handoff: temporary share link for a business owner (sales demo), Opus
CEO: "part of the backend is temporarily sharing with the owner". Build it in hosting/ (+ a button in the maker):
1. Maker: button "Share with the owner" (next to Download). It sends the current form JSON (look, trade, variant, credibility, pictures by library path or uploaded data) to the hosted backend POST /api/demo with header X-Agency-Key (the agency key is typed once in the maker and kept in localStorage; never in the page source). Returns a link like https://<worker host>/d/<token> plus expiry; the maker shows it with a Copy button and a QR code.
2. Backend: demo_links table (token 128-bit random, site form JSON or demo site id, created_at, expires_at default 14 days, views, last_view). GET /d/<token> renders the site exactly like a live site (same render, library pictures allowed because it is a demo), with: a slim top banner "Sample website made for <Company> by <agency>. Like it? Call/text <agency phone>" (agency phone from env AGENCY_PHONE), noindex/nofollow meta + X-Robots-Tag, no schema.org rating, the contact form sends leads to the AGENCY (not the owner) tagged 'demo'. Expired -> friendly page "This sample has expired, ask for a new one". Desk: list demo links (company, created, views, expires), buttons extend 7 days / revoke / turn into a real site (prefills new-site).
3. Security: agency key checked with constant-time compare; rate limit /api/demo; tokens unguessable; body size limits; escape everything; CORS only from the maker host(s) (env MAKER_ORIGINS).
4. Tests in hosting/test (create, view count, expiry, revoke, noindex, lead goes to agency, bad key 401) + sitemaker test for the button; npm test + sitemaker test-all green from a fresh clone. Update GO-LIVE.md (AGENCY_PHONE, MAKER_ORIGINS, AGENCY_KEY secret).
5. Report in org/inbox/chief.md with head sha; set BATON row done; push. The chief deploys and tests live.
