# Lifetime Roofing: measured spec (2 Nov, Playwright computed styles) vs ours. Team decisions marked DO.
| Detail | Lifetime | Ours (live test site) | DO |
|---|---|---|---|
| Top bar | dark strip: offer + phone + Book online, 16px/700 | none | add offer bar (offer from maker, phone, Free estimate) |
| Header | logo 117x80, 8 links 18px/500, Call Now + Book Now buttons | name only, 3 links 24px tall | logo slot (owner upload; text wordmark fallback), <=5 links, Call + Free estimate buttons 48px |
| H1 | Archivo 900, 56px desktop / 32px phone, who+where+'Top-Rated' | Instrument Serif 500, 104/48px, poetic | Classic: bold sans 900 ~56/34px. Cinematic/Editorial: keep serif but heavier/shorter, max ~72/40px, who+where+promise |
| Sub | 20px/32 line: services, years, rating, certified; 3 green check bullets | none | add sub line + 3 checks from credibility profile |
| Form | IN HERO right column desktop (name,email,phone,address,city,zip), below hero phone | none above fold, far down | DO: form in hero on desktop (all looks; Cinematic: right card over first story frame), phone: big button jumps to form |
| Primary CTA | green 'Book Your Free Inspection' 62px tall + 'or call' line | orange Call 52px | one primary color CTA >=60px + 'or call (xxx)' text link |
| Proof logos | badge images (Owens Corning, CertainTeed, BBB A+) right under hero | text badges | badge row under hero; only certifications the owner typed; real manufacturer logos only if the owner uploads them (trademark), else styled text badges |
| Phone bottom bar | 2 half buttons: Call Now (green) / Book Now (dark), 47px | 1 call button | 2 half buttons: Call / Free estimate |
| Sections | 17: credentials, services grid w/ tags, featured project + scope bullets, what's included, service pages, FAQ, blog, service areas, final CTA band, big footer | 3 | add: credentials, services grid w/ tags, featured project (before/after + scope bullets), what's included, FAQ, service areas, final CTA band, full footer |
Each look keeps its personality: Cinematic keeps the scroll story under the hero; Editorial keeps photo cards; Classic is the Lifetime format, cleaner.
